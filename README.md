# CTF

Github pages platform for hosting CTFs. Right now availible [here](https://xantus10.github.io/CTF/) with a few CTFs created by me.

Note: Developed in React.JS

## Featured CTFs

 - Easy crypto CTF - Challenges aimed at encoding, ciphers and hashes
 - MITRE Chain CTF - Explore the entire chain of compromise from Recon to Impact with some simple challenges
 - Malware focused CTF - Challenges focusing on digital forensics + malware analysis
